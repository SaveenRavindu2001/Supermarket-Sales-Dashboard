# Supermarket-Sales-Dashboard
An interactive Excel dashboard for analyzing supermarket sales, customer behavior, product performance, and revenue using Pivot Tables, charts, and slicers.

## Project Objective

To analyze supermarket sales data, identify sales trends, evaluate product and branch performance, understand customer purchasing behavior, and support better business decisions through an interactive Excel dashboard.

## Dataset used
- <a href="https://github.com/SaveenRavindu2001/Supermarket-Sales-Dashboard/blob/main/supermarket_sales%20-%20Sheet1.xlsx">Dataset</a>

## Questions (KPI'S)
- What is the total sales revenue?
- Which branch generates the highest sales?
- Which product line performs best?
- Which customer type contributes more to sales?
- Which payment method is most popular?
- Which city has the highest sales?
- What is the total gross income?
- How satisfied are customers with the products?

## Process

- Data Collection – Import supermarket sales data into Excel.
- Data Cleaning – Check and organize the dataset.
- Data Analysis – Analyze sales, customers, products, and branches.
- Pivot Tables – Create Pivot Tables to summarize key information.
- Data Visualization – Create charts and KPI cards.
- Dashboard Development – Design an interactive dashboard using slicers.
- Insights Generation – Identify trends and support data-driven decisions.
